Mixed-Precision Execution Model: FP32 GPU + FP64 CPU Polish

PDHG iterations execute matrix-vector multiplications in native single-precision (FP32/TF32) on Tensor Cores to maximize memory bandwidth throughput and minimize VRAM pressure. Upon achieving a relaxed residual threshold (1e-4), basis factorization or projected gradient polishing runs in double-precision (FP64) on host AVX-512 CPU threads to guarantee 1e-8 exact feasibility and avoid numerical drift.
